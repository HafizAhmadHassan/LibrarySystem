# Library System
*Created: 2019-12-19*

A **C++ library management system** built during a computer programming course.

## Overview

Implements the core data structures for a small library — books and members/membership — with a driver program that exercises the functionality. A practical introduction to data structures in C++.

## Features

- Book and member / membership data structures
- Driver program for demonstration

## Tech Stack

C++, data structures, OOP.

## Status

Completed course project.
